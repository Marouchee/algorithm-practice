# S02 꽃가루 모으기 (직접 만든 연습 문제, 표준 입력 형식)

N×M 화단의 칸마다 꽃이 한 송이씩 있고, 칸에 적힌 수 k(0~9)는 그 꽃의 꽃가루 양이다.
꽃 하나를 흔들면 그 칸의 꽃가루 k와 함께, **위·아래·왼쪽·오른쪽 네 방향으로 각각 k칸까지** 있는 꽃의 꽃가루가 모두 모인다.
화단 밖으로 나가는 칸은 없으므로 세지 않는다. 다른 꽃은 연쇄로 흔들리지 않는다.

꽃 하나만 흔들 수 있을 때, 모을 수 있는 꽃가루의 최댓값을 구하라.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, M (1 ≤ N, M ≤ 100)
- 다음 N줄에 M개의 정수가 공백으로 주어진다 (0 ≤ 각 수 ≤ 9)

## 출력
테스트 케이스마다 `#번호 답`을 한 줄에 출력한다.

## 예제 입력
```
2
3 4
1 0 2 1
3 1 0 4
0 2 1 1
5 5
0 1 0 2 1
1 2 1 0 3
0 4 1 1 0
2 0 1 3 1
1 1 0 1 2
```

## 예제 출력
```
#1 10
#2 11
```

예제 1: 1행 3열(0부터 셈)의 4를 흔들면 4 + 위 1 + 아래 1 + 왼쪽 (0 + 1 + 3) = 10. 오른쪽은 화단 밖이다.
