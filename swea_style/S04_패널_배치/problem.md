# S04 패널 배치 (직접 만든 연습 문제, 표준 입력 형식)

N×N 옥상의 칸마다 하루 햇빛 양(0~30)이 적혀 있다.
M×M 크기의 정사각형 태양광 패널 하나를 옥상 **안에 완전히 들어가게**, 칸에 맞춰 놓는다.
패널이 덮은 M×M칸의 햇빛 양을 모두 더한 값이 그 자리의 발전량이다.

가장 큰 발전량과, **그 발전량이 나오는 자리의 개수**를 구하라.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, M (1 ≤ M ≤ N ≤ 50)
- 다음 N줄에 N개의 정수가 공백으로 주어진다 (0 ≤ 각 수 ≤ 30)

## 출력
테스트 케이스마다 `#번호 최대발전량 자리수`를 한 줄에 출력한다.

## 예제 입력
```
2
4 2
1 3 0 2
2 0 5 1
4 1 1 3
0 2 2 0
5 3
2 0 1 0 2
1 1 1 1 1
0 2 0 2 0
1 1 1 1 1
2 0 1 0 2
```

## 예제 출력
```
#1 10 1
#2 10 1
```
