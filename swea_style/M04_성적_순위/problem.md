# M04 성적 순위 (직접 만든 연습 문제, 표준 입력 형식, 80분 3문제 세트의 2번)

N명의 학생이 국어, 영어, 수학 시험을 봤다. 학생 번호는 입력 순서대로 1번부터 N번이다.
학생들의 순위를 아래 규칙으로 정한다. 위의 규칙으로 갈리지 않을 때만 다음 규칙을 본다.

1. 세 과목 **총점**이 높은 학생이 앞선다
2. 총점이 같으면 **수학** 점수가 높은 학생이 앞선다
3. 수학도 같으면 **영어** 점수가 높은 학생이 앞선다
4. 영어도 같으면 학생 **번호**가 작은 학생이 앞선다

이 규칙으로 모든 학생의 순위가 1위부터 N위까지 하나씩 정해진다.
**K위** 학생의 번호와 그 학생의 총점을 구하라.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, K (1 ≤ K ≤ N ≤ 1,000)
- 다음 N줄에 i번 학생의 **국어, 영어, 수학** 점수가 이 순서로 공백으로 주어진다 (0 이상 100 이하 정수)

## 출력
테스트 케이스마다 `#번호 학생번호 총점`을 한 줄에 출력한다.

## 예제 입력
```
3
5 2
80 90 70
95 60 85
70 70 70
100 100 100
60 90 90
1 1
0 0 0
4 3
50 60 70
90 50 40
60 50 70
100 10 70
```

## 예제 출력
```
#1 5 240
#2 1 0
#3 4 180
```

예제 1: 1위는 4번(300점). 1번·2번·5번은 모두 240점이고 수학이 가장 높은 5번이 2위다.
