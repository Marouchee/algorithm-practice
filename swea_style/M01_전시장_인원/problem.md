# M01 전시장 인원 (직접 만든 연습 문제, 표준 입력 형식, 80분 2문제 세트의 1번)

어느 전시장에 하루 동안 N개의 단체가 다녀갔다. 단체마다 **입장 시각**, **퇴장 시각**, **인원 수**가 기록되어 있다.
시각은 `HH:MM` 형식(00:00 ~ 23:59)이며 모두 같은 날이다.

입장 시각이 `a`, 퇴장 시각이 `b`인 단체는 `a`분부터 `b`분 **직전**까지 전시장 안에 있다.
즉 `b`분이 되는 순간에는 이미 나가고 없다. 예를 들어 10:00에 나가는 단체와 10:00에 들어오는 단체는 전시장 안에서 만나지 않는다.

하루 중 전시장 안에 있던 사람 수가 **가장 많았던 순간의 인원**과, 그 인원이 **처음** 나온 시각을 구하라.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 단체 수 N (1 ≤ N ≤ 1,000)
- 다음 N줄에 입장 시각, 퇴장 시각, 인원 수 P가 공백으로 주어진다
  - 입장 시각 < 퇴장 시각, 1 ≤ P ≤ 100

## 출력
테스트 케이스마다 `#번호 최대인원 시각`을 한 줄에 출력한다. 시각은 입력과 같은 `HH:MM` 형식으로 쓴다.

## 예제 입력
```
3
4
09:00 11:30 3
10:00 10:30 5
11:30 12:00 4
10:15 12:00 2
1
00:00 23:59 7
3
08:00 09:00 5
12:00 13:00 2
12:30 12:45 3
```

## 예제 출력
```
#1 10 10:15
#2 7 00:00
#3 5 08:00
```

예제 1: 10:15 ~ 10:29에는 3 + 5 + 2 = 10명이 있다.
예제 3: 08:00과 12:30에 모두 5명이지만, 먼저 나온 08:00을 출력한다.
