# S09 가장 가까운 충전소 (직접 만든 연습 문제, 표준 입력 형식)

N행 M열 바닥에 청소 로봇 `R` 하나와 충전소 `C` 하나 이상이 있다. `#`은 벽, `.`은 빈 칸이다.
로봇은 한 번에 **위·아래·왼쪽·오른쪽으로 한 칸** 움직일 수 있고, 벽과 바닥 밖으로는 갈 수 없다. 충전소 칸과 빈 칸은 지나갈 수 있다.

로봇이 **가장 가까운 충전소**까지 가는 데 필요한 최소 이동 횟수를 구하라. 어느 충전소에도 갈 수 없으면 `-1`을 출력한다.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, M (1 ≤ N, M ≤ 100)
- 다음 N줄에 길이 M인 글자열이 **공백 없이** 주어진다 (`R` 정확히 1개, `C` 1개 이상)

## 출력
테스트 케이스마다 `#번호 답`을 한 줄에 출력한다.

## 예제 입력
```
3
4 5
R..#.
.#.#C
.#...
...#.
3 3
R#C
##.
...
2 4
C..R
...C
```

## 예제 출력
```
#1 7
#2 -1
#3 1
```

예제 3: 아래쪽 충전소까지 1번, 왼쪽 충전소까지 3번 → 가까운 쪽 1.
