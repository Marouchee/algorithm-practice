# S07 카드 합 맞추기 (직접 만든 연습 문제, 표준 입력 형식)

자연수가 적힌 카드 N장과 목표 수 K가 있다.
카드를 **한 장 이상** 골라 적힌 수를 모두 더한다. 고른 카드의 합과 K의 차이(절댓값)가 가장 작게 되도록 고르려 한다.

가장 작은 차이와, **그 차이가 나오는 고르는 방법의 수**를 구하라.
카드는 적힌 수가 같아도 서로 다른 카드로 본다. 고르는 순서는 상관없다(같은 카드 묶음은 한 가지 방법).

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, K (1 ≤ N ≤ 16, 1 ≤ K ≤ 1600)
- 다음 줄에 카드 N장의 수가 공백으로 주어진다 (1 ≤ 각 수 ≤ 100)

## 출력
테스트 케이스마다 `#번호 최소차이 방법수`를 한 줄에 출력한다.

## 예제 입력
```
4
4 10
3 5 6 8
3 6
1 2 3
1 100
7
5 7
1 2 3 4 5
```

## 예제 출력
```
#1 1 3
#2 0 1
#3 93 1
#4 0 3
```

예제 1: 3 + 6 = 9, 3 + 8 = 11, 5 + 6 = 11 세 가지가 K = 10과 1 차이로 가장 가깝다.
