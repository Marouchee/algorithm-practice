# S06 회문 줄 (직접 만든 연습 문제, 표준 입력 형식)

N행 M열 판의 칸마다 대문자 하나(A, B, C 중 하나)가 적혀 있다.
한 행에서 **연속한 칸**을 왼쪽에서 오른쪽으로 읽거나, 한 열에서 **연속한 칸**을 위에서 아래로 읽은 글자열 중
앞에서 읽어도 뒤에서 읽어도 같은 것(회문)을 찾는다. **길이가 2 이상인 것만** 센다.

가장 긴 회문의 길이와, **그 길이인 회문 구간의 개수**(가로 구간과 세로 구간을 모두 센다)를 구하라.
길이 2 이상인 회문이 하나도 없으면 `0 0`을 출력한다.

예: 행이 `ABBA`이면 그 행에서 찾는 회문은 `ABBA`(길이 4)와 `BB`(길이 2)다.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, M (1 ≤ N, M ≤ 30)
- 다음 N줄에 길이 M인 글자열이 **공백 없이** 주어진다

## 출력
테스트 케이스마다 `#번호 최장길이 개수`를 한 줄에 출력한다.

## 예제 입력
```
3
3 4
ABBA
CACB
ABCA
2 2
AB
BA
4 5
ABCBA
BACAB
CCACC
BACAB
```

## 예제 출력
```
#1 4 1
#2 0 0
#3 5 4
```

예제 1: 가로 `ABBA`(길이 4)가 가장 길다. 세로에는 `ACA`, `BAB`, `ABA`(길이 3)와 `CC`(길이 2)가 있다.
