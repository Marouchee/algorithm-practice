# M05 레이저 거울 (직접 만든 연습 문제, 표준 입력 형식, 80분 3문제 세트의 3번)

N행 M열 판의 칸마다 아래 글자 중 하나가 놓여 있다.

| 글자 | 뜻 |
|---|---|
| `.` | 빈 칸. 빛이 그대로 지나간다 |
| `/` | 거울. 빛이 꺾인다 |
| `\` | 거울. 빛이 꺾인다 |
| `#` | 벽. 빛이 들어가지 못하고 그 앞에서 사라진다 |

거울에 닿은 빛은 다음처럼 방향을 바꾼다.

| 들어오던 방향 | `/`를 만나면 | `\`를 만나면 |
|---|---|---|
| 오른쪽으로 가던 빛 | 위로 | 아래로 |
| 왼쪽으로 가던 빛 | 아래로 | 위로 |
| 위로 가던 빛 | 오른쪽으로 | 왼쪽으로 |
| 아래로 가던 빛 | 왼쪽으로 | 오른쪽으로 |

판 바깥에서 레이저를 한 번 쏜다. 쏠 수 있는 곳은 판 테두리 바깥의 모든 칸이며, 빛은 판의 변과 **수직으로** 들어온다.

- 각 행의 왼쪽 바깥에서 오른쪽으로, 각 행의 오른쪽 바깥에서 왼쪽으로
- 각 열의 위쪽 바깥에서 아래로, 각 열의 아래쪽 바깥에서 위로

즉 쏘는 방법은 모두 2 × (N + M)가지다.

빛은 판 밖으로 나가거나 벽(`#`)을 만나면 사라진다. 빛이 한 번이라도 지나간 칸(거울 칸 포함, 벽 칸 제외)을 **밝혀진 칸**이라고 한다. 같은 칸을 여러 번 지나가도 한 칸으로 센다.

한 번 쏘아서 밝힐 수 있는 칸 수의 **최댓값**을 구하라. 어떻게 쏘아도 밝혀지는 칸이 없으면 0을 출력한다.

빛은 항상 언젠가 판 밖으로 나가거나 벽에서 사라진다.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, M (1 ≤ N, M ≤ 50)
- 다음 N줄에 길이 M인 글자열이 **공백 없이** 주어진다 (`.`, `/`, `\`, `#`로만 이루어짐)

## 출력
테스트 케이스마다 `#번호 최댓값`을 한 줄에 출력한다.

## 예제 입력
```
3
3 4
.\..
....
.\./
1 1
#
2 5
.#./.
..\#.
```

## 예제 출력
```
#1 8
#2 0
#3 3
```

예제 1: 1행 왼쪽 바깥에서 오른쪽으로 쏘면 (1,1) → (1,2)에서 아래로 → (2,2) → (3,2)에서 오른쪽으로 → (3,3) → (3,4)에서 위로 → (2,4) → (1,4)를 지나 판 밖으로 나간다. 8칸이 밝혀진다. (행, 열은 1부터 셌다)
