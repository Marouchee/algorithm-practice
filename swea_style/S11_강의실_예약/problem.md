# S11 강의실 예약 (직접 만든 연습 문제, 표준 입력 형식)

강의실 하나에 수업 N개가 예약을 신청했다. 수업 i는 시각 `s`에 시작해 시각 `e`에 끝난다.
한 강의실에서는 수업이 겹치면 안 된다. 단, 한 수업이 끝나는 시각에 다른 수업이 **바로 시작하는 것은 된다** (끝 10, 시작 10은 가능).

겹치지 않게 고를 수 있는 수업의 **최대 개수**를 구하라.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N (1 ≤ N ≤ 10,000)
- 다음 N줄에 두 정수 s, e (0 ≤ s < e ≤ 1,000,000). 같은 수업이 여러 번 나올 수 있다

## 출력
테스트 케이스마다 `#번호 최대개수`를 한 줄에 출력한다.

## 예제 입력
```
3
5
1 4
3 5
0 6
5 7
8 9
3
1 10
2 3
4 5
4
1 3
3 5
5 7
2 6
```

## 예제 출력
```
#1 3
#2 2
#3 3
```
