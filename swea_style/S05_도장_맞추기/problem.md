# S05 도장 맞추기 (직접 만든 연습 문제, 표준 입력 형식)

N×N 칸으로 된 도장 무늬 A와 찍혀 있는 자국 B가 있다. 칸마다 0~9가 적혀 있다.
도장 A는 **시계 방향으로 90도씩만** 돌릴 수 있다. 뒤집을 수는 없다.

A를 몇 번 돌리면 B와 모든 칸이 같아지는지 구하라.
같아지는 횟수가 여럿이면 **가장 작은 횟수(0~3)**를, 네 방향 어느 것도 B와 같지 않으면 **-1**을 출력한다.

시계 방향 90도 회전 예 (N = 3):
```
1 2 3        7 4 1
4 5 6   →    8 5 2
7 8 9        9 6 3
```

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N (1 ≤ N ≤ 50)
- 다음 N줄에 A의 각 행이 N개의 정수로 주어진다
- 다음 N줄에 B의 각 행이 N개의 정수로 주어진다 (0 ≤ 각 수 ≤ 9)

## 출력
테스트 케이스마다 `#번호 답`을 한 줄에 출력한다.

## 예제 입력
```
4
3
1 2 3
4 5 6
7 8 9
9 8 7
6 5 4
3 2 1
2
1 0
0 1
0 1
1 0
2
1 2
3 4
2 4
1 3
2
1 2
3 4
1 2
4 3
```

## 예제 출력
```
#1 2
#2 1
#3 3
#4 -1
```
