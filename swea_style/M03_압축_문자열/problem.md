# M03 압축 문자열 (직접 만든 연습 문제, 표준 입력 형식, 80분 3문제 세트의 1번)

긴 문자열을 짧게 보내려고 다음 규칙으로 압축했다.

- 같은 글자가 여러 번 이어지면 글자 뒤에 반복 횟수를 쓴다. 예: `ccccc` → `c5`
- 반복 횟수가 1이면 숫자를 쓰지 않을 수도 있고, `1`을 쓸 수도 있다. 예: `b`와 `b1`은 둘 다 `b`

예를 들어 `a3bc12d`를 펼치면 `aaa` + `b` + `cccccccccccc` + `d`가 되어 길이가 17이다.

압축된 문자열 S와 수 K가 주어질 때, S를 펼친 문자열의 **길이**와, 펼친 문자열의 **K번째 글자**(1부터 센다)를 구하라.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스는 한 줄이며, 압축된 문자열 S와 K가 공백으로 주어진다
  - S의 길이는 1 이상 1,000 이하
  - S는 알파벳 소문자와 숫자로만 이루어지고, 첫 글자는 소문자다
  - 반복 횟수는 1 이상 999 이하이며 0으로 시작하지 않는다
  - 1 ≤ K ≤ (펼친 문자열의 길이)

## 출력
테스트 케이스마다 `#번호 길이 글자`를 한 줄에 출력한다.

## 예제 입력
```
3
a3bc12d 5
x 1
k10m2k 12
```

## 예제 출력
```
#1 17 c
#2 1 x
#3 13 m
```
