# S08 작업 순서 (직접 만든 연습 문제, 표준 입력 형식)

기계 한 대로 작업 N개(0번 ~ N-1번)를 **모두 한 번씩** 처리한다. 순서는 마음대로 정할 수 있다.
작업 a를 끝내고 바로 다음에 작업 b를 하려면 준비 시간 `S[a][b]`가 든다. 첫 작업은 준비 시간이 없다.

모든 작업을 처리하는 순서 중 **준비 시간 합의 최솟값**을 구하라.

예: N = 3, 순서가 2 → 0 → 1이면 준비 시간 합은 `S[2][0] + S[0][1]`이다.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N (1 ≤ N ≤ 9)
- 다음 N줄에 S의 각 행이 N개의 정수로 주어진다. `S[a][a]` = 0, 나머지는 1 이상 100 이하

## 출력
테스트 케이스마다 `#번호 답`을 한 줄에 출력한다.

## 시간 제한 (연습용 가정)
최대 입력(T = 10, N = 9)을 PyPy3.7로 **1초 안에** 끝내야 한다.

## 예제 입력
```
3
3
0 5 2
3 0 7
4 1 0
1
0
4
0 8 3 9
4 0 6 2
7 5 0 1
6 3 8 0
```

## 예제 출력
```
#1 3
#2 0
#3 7
```

예제 1: 순서 0 → 2 → 1이면 `S[0][2] + S[2][1]` = 2 + 1 = 3.
