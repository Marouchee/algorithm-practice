# M02 창고 로봇 (직접 만든 연습 문제, 표준 입력 형식, 80분 2문제 세트의 2번)

N행 M열 창고 바닥을 택배 로봇 한 대가 움직인다. 칸마다 아래 글자 중 하나가 적혀 있다.

| 글자 | 뜻 |
|---|---|
| `.` | 빈 바닥 |
| `#` | 선반. 로봇이 들어갈 수 없다 |
| `P` | 택배가 하나 놓인 바닥 |
| `D` | 배달 지점 |

로봇은 처음에 (R, C) 칸에서 방향 d를 보고 있다. 방향은 `0`: 위, `1`: 오른쪽, `2`: 아래, `3`: 왼쪽이다.
로봇은 택배를 **최대 K개**까지 들 수 있고, 처음에는 하나도 들고 있지 않다.

명령 문자열을 앞에서부터 한 글자씩 수행한다.

- `L`: 제자리에서 왼쪽으로 90도 돈다
- `R`: 제자리에서 오른쪽으로 90도 돈다
- `F`: 보고 있는 방향으로 한 칸 간다
  - 그 칸이 창고 밖이거나 선반(`#`)이면 **움직이지 않고, 제자리에서 뒤로 돈다** (보는 방향이 반대가 된다)
  - 새 칸에 도착했을 때
    - `P` 칸이면: 들고 있는 택배가 K개보다 적을 때만 택배를 집는다. 집은 칸은 빈 바닥(`.`)이 된다. 이미 K개를 들고 있으면 그냥 지나간다(택배는 그 칸에 남는다)
    - `D` 칸이면: 들고 있는 택배를 **모두** 배달한다. 배달 지점은 그대로 남아 몇 번이든 쓸 수 있다

모든 명령을 수행한 뒤 아래 네 값을 구하라.
1. 로봇의 행 번호, 2. 열 번호 (둘 다 **1부터** 센다)
3. 지금까지 배달한 택배의 총 개수
4. 창고 바닥에 **남아 있는** 택배 개수 (로봇이 들고 있는 택배는 세지 않는다)

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, M, K (1 ≤ N, M ≤ 50, 1 ≤ K ≤ 10)
- 다음 줄에 R, C, d (1 ≤ R ≤ N, 1 ≤ C ≤ M, 0 ≤ d ≤ 3). 시작 칸은 항상 `.`이다
- 다음 N줄에 길이 M인 글자열이 **공백 없이** 주어진다
- 다음 줄에 명령 문자열이 주어진다 (길이 1 이상 1,000 이하, `L`·`R`·`F`로만 이루어짐)

## 출력
테스트 케이스마다 `#번호 행 열 배달개수 남은택배`를 한 줄에 출력한다.

## 예제 입력
```
2
4 5 2
1 1 1
.PP.#
.#P..
.D...
P...D
FFFRFFRFFLF
1 3 5
1 2 3
P.D
FFFF
```

## 예제 출력
```
#1 4 2 2 2
#2 1 3 1 0
```

예제 2: 왼쪽으로 한 칸 가서 택배를 집고, 다음 `F`에서 창고 밖이라 뒤로 돌아 오른쪽을 본다. 이어서 두 칸 가서 배달 지점에 도착한다.
