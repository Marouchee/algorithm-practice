# S03 달팽이 번호 (직접 만든 연습 문제, 표준 입력 형식)

N행 M열 판의 맨 왼쪽 위 칸에서 시작해 1, 2, 3, …, N×M을 차례로 적는다.
처음에는 **오른쪽**으로 가다가, 판 밖으로 나가거나 이미 적힌 칸을 만나면 **시계 방향으로 90도** 돌아서(오른쪽 → 아래 → 왼쪽 → 위 → 오른쪽 …) 계속 적는다.

예: N = 3, M = 4
```
 1  2  3  4
10 11 12  5
 9  8  7  6
```

다 적은 뒤 Q개의 칸 (r, c)에 적힌 수를 묻는다. 행과 열은 **1부터** 센다.

## 입력
- 첫 줄에 테스트 케이스 수 T (1 ≤ T ≤ 10)
- 각 테스트 케이스의 첫 줄에 N, M (1 ≤ N, M ≤ 100)
- 다음 줄에 질문 수 Q (1 ≤ Q ≤ 10)
- 다음 Q줄에 r, c (1 ≤ r ≤ N, 1 ≤ c ≤ M)

## 출력
테스트 케이스마다 `#번호` 뒤에 Q개의 답을 질문 순서대로 공백으로 나누어 한 줄에 출력한다.

## 예제 입력
```
2
3 4
3
1 1
2 1
2 3
5 3
2
3 2
5 1
```

## 예제 출력
```
#1 1 10 12
#2 14 9
```
