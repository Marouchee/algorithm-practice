# 문법 드릴 06: itertools

## 6-1. 개수 예측

| | 식 | 4개 중 2개 |
|---|---|---|
| `permutations(arr, 2)` | n × (n−1) | 12 |
| `combinations(arr, 2)` | n × (n−1) ÷ 2 | 6 |
| `product(arr, repeat=2)` | n × n | 16 |

## 6-2. combinations

`menu = [("coffee", 4), ("cake", 6), ("juice", 5), ("cookie", 2)]`에서 서로 다른 메뉴 2개의 가격 합이 10 이하인 조합의 개수 → `5`

## 6-3. permutations + join

`cards = ["1", "7", "0"]`에서 카드 2장을 순서대로 붙여 만든 두 자리 수(앞자리 0 제외)를 오름차순 정수 리스트로 → `[10, 17, 70, 71]`

## 6-4. 시간 복잡도 감각

n = 10,000에서 2개 조합을 전부 돌면 약 5천만 번. 파이썬 1초 1천만~2천만 번 기준으로 안전하지 않다.
