# 문법 드릴 01: list 슬라이싱 · 컴프리헨션 · 2차원 리스트

## 1-1. 슬라이싱

`temps = [12, 15, 9, 20, 18, 7, 25]`에서 각각 표현식 한 줄로 구한다.

- (a) 마지막 3개 → `[18, 7, 25]` (길이에 묶인 상수 없이)
- (b) 뒤집은 리스트 → `[25, 7, 18, 20, 9, 15, 12]`
- (c) 인덱스가 짝수인 원소 → `[12, 9, 18, 25]`

## 1-2. 컴프리헨션

`words = ["apple", "kiwi", "banana", "fig", "cherry"]`에서 길이 5 이상인 단어만 대문자로 바꾼다.
→ `["APPLE", "BANANA", "CHERRY"]`

## 1-3. 2차원 리스트 만들기

0으로 채운 3행 4열 격자를 만든다. `grid[1][2] = 5`를 해도 1번 행만 바뀌어야 한다.

## 1-4. 2차원 순회

`board = [[1, 2, 3], [4, 5, 6]]`

- (a) 전치 → `[[1, 4], [2, 5], [3, 6]]` (`zip` 없이)
- (b) 열 합 → `[5, 7, 9]`
