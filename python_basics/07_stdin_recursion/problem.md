# 문법 드릴 07: 표준 입력 · 재귀 한도

## 7-1. 숫자 격자 입력

첫 줄 `n m`, 다음 n줄에 공백으로 나뉜 정수 m개. 2차원 리스트로 받고 1의 개수를 출력한다.

```
3 4
1 0 1 1
0 0 1 0
1 1 1 1
```
→ `8`

## 7-2. 출력 예측

```python
line = "101\n"
print(list(line))                          # ['1', '0', '1', '\n']
print(len(line))                           # 4  ('\n'은 한 글자)
print([int(c) for c in line.rstrip()])     # [1, 0, 1]
```

## 7-3. 공백 없는 격자 입력

```
2 3
101
011
```
→ `[[1, 0, 1], [0, 1, 1]]`

## 7-4. 재귀 한도

깊이 5000인 재귀는 기본 한도(1000)를 넘어 `RecursionError`가 난다. `sys.setrecursionlimit(10**6)`으로 늘린다.
호출마다 콜 스택에 프레임이 쌓이므로, 스택이 넘쳐 프로세스가 죽기 전에 에러로 멈추도록 제한을 둔다.

## 메모

- `input = sys.stdin.readline`은 읽는 **함수**에 이름을 붙인 것이다. 한 줄을 읽으려면 매번 `input()`을 호출한다.
