# 003. 순찰 로봇 (백트래킹)

R행 C열 격자가 있다. 각 칸은 빈칸 `.` 또는 벽 `#`이다. 격자 위에 체크포인트 M개가 1번부터 M번까지 정해져 있다.

로봇은 1번 체크포인트에서 출발해 상하좌우로 한 칸씩 움직인다. 아래 규칙을 지켜 **M번 체크포인트에 도착하면** 순찰이 끝난다.

- 벽이나 격자 밖으로는 갈 수 없다.
- 한 번 지나간 칸(출발 칸 포함)은 다시 들어갈 수 없다.
- 체크포인트는 번호 순서대로 들러야 한다. 아직 차례가 아닌 체크포인트 칸에는 들어갈 수 없다.
- 로봇의 배터리로는 최대 K번까지만 움직일 수 있다.

순찰을 마칠 수 있는 서로 다른 이동 경로의 수를 출력하라. 가능한 경로가 없으면 0을 출력한다.

### 입력

`solution(grid, checkpoints, k)` 형태로 받는다. grid는 길이 C인 문자열 R개, checkpoints는 `[[행, 열], ...]`(1부터 시작), k는 최대 이동 횟수. 반환값은 경로 수(int).

아래는 같은 입력의 텍스트 형태다.

- 첫 줄: `R C M K`
- 다음 R줄: 길이 C의 문자열 (`.` 또는 `#`)
- 다음 M줄: i번 체크포인트의 `행 열` (1부터 시작). 체크포인트는 서로 다른 빈칸에 있다.

### 제약

- 2 ≤ R, C ≤ 4
- 2 ≤ M ≤ R × C
- 1 ≤ K ≤ R × C

### 예제

| 입력 | 출력 |
|---|---|
| `ex1_1.txt` | `12` |
| `ex1_2.txt` | `1` |
| `ex1_3.txt` | `6` |

```
ex1_1.txt        ex1_2.txt        ex1_3.txt
3 3 2 8          3 3 3 8          3 3 2 4
...              ...              ...
...              .#.              ...
...              ...              ...
1 1              1 1              1 1
3 3              1 3              3 3
                 3 3
```
