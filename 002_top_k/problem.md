# 002. 조회수 Top K 상품

상품 조회 로그 `views`(상품 id 문자열 목록)와 정수 `k`가 주어진다. 조회 수가 많은 순으로 상품 id `k`개를 반환한다. 조회 수가 같으면 id 사전순으로 앞선 것이 먼저다. 서로 다른 상품이 `k`개보다 적으면 전부 반환한다.

```python
def top_k(views: list[str], k: int) -> list[str]:
    ...
```

- `1 <= len(views) <= 10^5`, `1 <= k <= 10^5`

## 예시 (`views = ["b","a","c","a","b","a","d"]`)

| k | 출력 | 이유 |
|---|---|---|
| 2 | `["a","b"]` | 조회 수 순 |
| 3 | `["a","b","c"]` | c와 d가 1회로 같아 사전순으로 c |
| 10 | `["a","b","c","d"]` | 상품이 4개뿐 |
